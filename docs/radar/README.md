## 依賴關係

```
第一期（排程、資料表、後台框架）
   ├──► 第二期（資安：沿用同一套排程、資料表與隱藏／遞補機制）
   └──► 第三期（收藏：參照 radar_items，需要第一期的榜單；第二期完成後資安項目也能收藏）
```

- 第二期和第三期都只依賴第一期，彼此獨立。如果想先用收藏功能，可以對調順序。
- 每一期都能單獨上線，上線後就有完整可用的功能，不需要等下一期。

## 已確定的設計決策

這些是規劃討論後定案的方向，三期都遵守：

| 決策               | 內容                                            | 原因                                                                    |
| ------------------ | ----------------------------------------------- | ----------------------------------------------------------------------- |
| 不使用 AI          | 不串接 OpenAI，所有內容來自官方資料與自己的筆記 | 核心價值是有數據依據的榜單；省掉 API 費用、幻覺與 prompt injection 風險 |
| 只做週榜           | 不做月榜                                        | 快照每天都存，日後要加月榜只是把 7 天改成 30 天                         |
| 模組只有兩種狀態   | `hidden`（僅自己可見）／`public`                | 原本四層開關組合太多，難以測試                                          |
| 收藏一律私人       | 收藏、筆記、標籤只在後台看得到                  | 想公開就寫成文章，沿用現有文章的草稿／發佈流程                          |
| 榜單不寫成文章     | 榜單是資料頁，放在 `/radar`，不進 `posts` 表    | 避免文章列表、RSS、sitemap 被自動內容灌爆                               |
| 前台不放管理按鈕   | 所有管理操作集中在後台                          | 前台維持 `"use cache"` 靜態預渲染，不因讀取登入狀態變成動態頁           |
| 排名依據公開透明   | 每個榜單頁面都寫明統計方式、期間與最後同步時間  | 「客觀數據依據」的前提是讀者能驗證                                      |
| 排名不做人工加權   | 管理員可以隱藏項目，但不能調整名次              | 加權會讓「客觀排名」名不副實                                            |
| 排程用 Vercel Cron | 免費方案每天一次、函式最長 300 秒               | 每日快照剛好符合限制，不需要額外維護 GitHub Actions                     |

## 已移除的原始需求

| 原始需求                                        | 處理方式                                                           |
| ----------------------------------------------- | ------------------------------------------------------------------ |
| OpenAI 按需分析（搬運可行性快評、白話漏洞說明） | 移除，見 [backlog.md](backlog.md) 的「AI 功能重新評估」            |
| 文章編輯器「一鍵補齊 SEO／GEO／TL;DR」          | 移除（屬於 AI 功能）                                               |
| 技術棧 Release 追蹤器                           | 移除，和 Dependabot／Renovate 重疊；改列入未排期的「依賴漏洞比對」 |
| 月榜                                            | 移除，日後可加                                                     |
| 原始榜單層／單筆發佈狀態／首頁手動精選          | 簡化為模組 `hidden`／`public`，首頁改為自動取週榜前幾名            |
| 後台自訂「重點加權關鍵字」                      | 改成「關注關鍵字」只標記徽章、不影響名次；保留「排除關鍵字」       |
